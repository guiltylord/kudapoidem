# КудаПойдем (VibeMatch)

Быстрый пульт организатора для выбора места в Москве за 15 секунд — без фреймворков, лишних вкладок и 40-минутных споров в чате.

**Демо:** https://guiltylord.github.io/kudapoidem/

## Как работает
1. Организатор на одном экране за 4 тапа отмечает ограничения компании из чата: день, вайб, бюджет по самому экономному другу и стоп-факторы (без кальянов, без орущей музыки, веган-опции, просторно, центр).
2. Алгоритм мгновенно подбирает **Топ-3 реальных места Москвы** с понятным объяснением, почему каждое подходит.
3. В 1 клик организатор копирует готовый опрос для группового чата Telegram (`1 / 2 / 3`) или сразу открывает маршрут на Яндекс Картах / 2GIS.
4. Все настройки сохраняются локально в `localStorage` для следующих встреч.

## Стек
Чистые HTML5 + CSS3 + Vanilla JavaScript.
